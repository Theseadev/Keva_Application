### 🧠 About The Project
**Keva (Keep-Value Data Saver Lab)** adalah aplikasi edukatif berbasis Android yang dibuat untuk mendemonstrasikan penyimpanan data sederhana menggunakan **SharedPreferences** dan **File Handling** di **Kotlin Jetpack Compose**.  
Aplikasi ini dikembangkan sebagai bagian dari tugas **Praktikum Pemrograman Mobile** di Universitas Antasari.

</div>

---

## ✨ Features
- 💾 **SharedPreferences Demo** — Menyimpan data kecil seperti nama dan NIM dengan key–value pairs  
- 📂 **File Handling Demo** — Membaca & menulis catatan di penyimpanan internal  
- 🎨 **Modern UI** — Menggunakan Jetpack Compose dengan warna lembut dan layout dinamis  
- 🚀 **Navigation Component** — Navigasi antar layar menggunakan `NavController`  
- 🌙 **Responsive Design** — Mendukung mode terang dan gelap
